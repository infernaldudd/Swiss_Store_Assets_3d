# Swiss Store Assets 3D

Seven game-ready illuminated Swiss storefront signs based on supplied storefront photographs: **LOOP**, **LOOP restaurant**, **AMIGOS**, the **AMIGOS double-A projecting sign**, a **single A**, a **triple A**, and a **Swiss-style AUSGANG / EXIT sign**.

The assets are intended for use in Unreal Engine 5.7 and other glTF-capable engines. All dimensions use **metres**. All seven exported `.glb` assets are in `assets/`. The three new signs have optional CPU-rendered previews generated by `RENDER_PREVIEWS=1 blender -b --python tools/build_additional_signs.py`. The signs have genuine 3D letters, visible depth, varied PBR materials, emissive faces, metal supports, and separate meshes for practical editing.

## Import

Import `assets/*.glb` using Unreal's **glTF Importer** plugin or drag them into a glTF-compatible engine. Front faces point toward the viewer; the original Blender geometry uses X horizontal, Z vertical, and negative Y outward. Place the back of the signs against the shop facade. Emissive materials make the letters luminous; for visible screen-space light spill activate Bloom and/or add local lighting in your level. Emission alone is not guaranteed to light nearby geometry.

These are **original fictional brands**, not official Coop or Migros assets. Two Blender generators under `tools/` make the seven exported models. `build_store_signs.py` generates the original four; `build_additional_signs.py` generates only the three newly requested signs. The GitHub Actions workflows export and validate the assets directly in the repository.\n\nThe AUSGANG / EXIT sign is intended as a **fictional game prop**, not as certified emergency safety equipment. For authentic environmental storytelling, position arrow directions consistently with actual building exits.
